# Android

The Gradle project of BaresipKit for Android: the libraries `baresipkit`, `baresipkit-audio`,
`baresipkit-video`, `baresipkit-telecom`, `baresipkit-push` and `baresipkit-compose`, and the
sample app [zvono](zvono/README.md).

The setup guide, with installation, a quick start, the setup recipes, building from source,
tests and releases, is [Docs/Android.md](../Docs/Android.md).
